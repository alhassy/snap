1. [ ] Let's explore org-like fontification within string literals!

   Let's make a new repo ~/fontified-docstrings whose purpose is to empower
   users to write better docstrings by having their docstrings look nicer in the
   source. E.g., 

   1. If I write Org-markup: *bold*, _underline_, /italics/ then I'd like
      the markup to look nice in the string literals.

   2. If I write “* some title” then we fontify that line bigger then the others
      since it denotes an org-mode section, likewise for “** subsection” and
      “*** sub-sub-section”.

   3. If I have an enumeration:

      + first
      + second
      + third

      Then fontify the “+” to be “⇒”.
      If I use “-” instead, then fontify it as “↳”.
      
   4. If a user writes ```...```` then the ...` is a code block and should be
      fontified in a monospace font. If a language is specified ```emacs-lisp
      then we should fontify that code block as if it were emacs lisp.

      Moreover, after the ```<lang> let's have an overlay [Run] so that
      users can press it to actually run the source block!

      Perhaps this will encourage users to write usage examples in docstrings!
